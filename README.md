## 📖 Project Description

This beginner-friendly Python project helps students calculate their total marks, average, and final grade based on input for three subjects. It displays a neat report card and also saves the result to a file named `report_card.txt`.

> This project was built using a mobile device on **Pydroid 3**, showing how programming is possible anywhere with passion.

---

## 🛠️ Features

- 📌 Input for 3 custom subject names and marks  
- ➕ Calculates **total** and **average** marks  
- 🏷️ Assigns **grades** based on average  
- 💾 Saves output to a `.txt` file  
- ✅ Clean, beginner-friendly Python code
